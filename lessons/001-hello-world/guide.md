# Hello, world

This is a placeholder for lesson 1. The real lesson is written later.

A program is a list of instructions. Python reads them from the top, one line at a time.

The first instruction to learn is `print()`. It shows something on the screen.

```python
print("Hello, world")
```

The words inside the quotes are called **text**. Python shows them exactly as you typed them.

You can print several things at once. Put a comma between them and Python adds a space for you.

```python
print("My name is", "Pip")
```
